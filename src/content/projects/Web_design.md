## Overview
I created a fully custom website for **Will's Remodeling LLC**, a local contracting business. The goal was to have a professional digital footprint to build trust with potential clients, showcase past work, and increase lead generation through improved online visibility. 

## My Role & The Tech Stack
* **Role:** Freelance Web Developer & UI Designer
* **Front-End:** Semantic HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript
* **Optimization:** Google Lighthouse, WebP Image Conversion
* **Skills:** Search Engine Optimization (SEO), Responsive UI/UX, Performance Tuning, Adobe tools

---

## The Engineering Process

### 1. Architecture & UI/UX Design
I opted for a custom build from the ground up using basic web programming. This had two benefits, first maximum control with fast load times. Second, was hands on practice with these front end programming languages. The UI was designed to be clean and modern, utilizing CSS Flexbox and Grid make the layout was fully responsive across desktop, tablet, and mobile devices because it is assumed that most people looking for a contractor will be looking on their phone. 

![Logo](/website/long_will_logo.webp)
*Caption: Logo that I created for the company*

### 2. Interactive Elements
I used vanilla JavaScript to handle client-side interactivity without the overhead of heavy frameworks. One example is the image gallery that organizes project photos which helps potential clients create vision of what their space could become. 

### 3. Performance & Next-Gen Optimization
A requirement for the website was high performance because the contractor was going for a luxury and trustworthy experience. A website that is sluggish does not accurately portray the high quality that the contractor was going for. To hit the requirement, I  converted all of the high-resolution portfolio images into the **WebP** next-gen format, which reduced the server payload without sacrificing visual quality.

### 4. Search Engine Optimization (SEO)
SEO was integrated into the architecture from day one. I structured the DOM using semantic HTML tags to help web crawlers understand the content hierarchy. Additionally, I made highly descriptive meta titles, optimized descriptions for each page, and strict accessibility compliance by applying `alt` text to all visual elements.

## Outcomes & Lighthouse Metrics
The final deployment successfully met all client requirements, providing a sleek, high-performing platform that serves as their primary lead-generation tool. The strict focus on core web vitals resulted in near-perfect Google Lighthouse scores across Performance, Accessibility, Best Practices, and SEO.

![Lighthouse Performance Score](/website/score.png)
*Caption: Google Lighthouse audit demonstrating near-perfect scores achieved through custom architecture and WebP optimization.*

Within the first 3 months there where over 60 different users and created several leads for the Owner of the company. Also googling "Remodeling in Lake Keowee area" has the website as one of the first websites that come up.
