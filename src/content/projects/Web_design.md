## Overview
I developed a fully custom website for **Will's Remodeling LLC**, a local contracting business. The primary objective was to establish a professional digital footprint to build trust with potential clients, showcase a portfolio of past work, and increase lead generation through improved online visibility. 

## My Role & The Tech Stack
* **Role:** Freelance Web Developer & UI Designer
* **Front-End:** Semantic HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript
* **Optimization:** Google Lighthouse, WebP Image Conversion
* **Skills:** Search Engine Optimization (SEO), Responsive UI/UX, Performance Tuning

---

## The Engineering Process

### 1. Architecture & UI/UX Design
Rather than relying on bloated website builders (like Wix or WordPress), I opted for a custom build from the ground up using core web technologies. This approach guaranteed maximum control over the DOM and ensured ultra-fast load times. The UI was designed to be clean and modern, utilizing CSS Flexbox and Grid to ensure the layout was fully responsive across desktop, tablet, and mobile devices.

### 2. Interactive Elements
I utilized vanilla JavaScript to handle client-side interactivity without the overhead of heavy frameworks. This included developing a dynamic image gallery to organize project photos, an interactive mobile navigation menu, and smooth DOM transitions to enhance the user experience.

### 3. Performance & Next-Gen Optimization
To ensure rapid loading speeds—a critical factor for both user retention and Google search rankings—I implemented strict performance optimizations. A major strategy was converting all high-resolution portfolio images into the **WebP** next-gen format, which drastically reduced the server payload without sacrificing visual quality.

### 4. Search Engine Optimization (SEO)
SEO was integrated into the architecture from day one. I structured the DOM using semantic HTML tags to help web crawlers understand the content hierarchy. Additionally, I crafted highly descriptive meta titles, injected optimized descriptions for each page, and ensured strict accessibility compliance by applying `alt` text to all visual elements.

## Outcomes & Lighthouse Metrics
The final deployment successfully met all client requirements, providing a sleek, high-performing platform that serves as their primary lead-generation tool. The strict focus on core web vitals resulted in near-perfect Google Lighthouse scores across Performance, Accessibility, Best Practices, and SEO.
